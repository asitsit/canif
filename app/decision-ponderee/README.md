# E4 : Matrice de décision pondérée

Adresse : `/decision-ponderee`.

- Options en colonnes (jusqu'à 8), critères en lignes avec un poids de 1 à 5, notes de 0 à 5.
- Score = somme(poids × note), en pourcentage du maximum ; meilleur score surligné.
- Noms modifiables, export image ou PDF. Composant commun `components/matrice-decision.tsx`.

# D5 : Export en image ou PDF

Adresse : `/export`.

- L'export est intégré aux 18 outils qui produisent un visuel (`components/boutons-export.tsx` : image PNG via `html-to-image`, impression ou PDF via la fenêtre d'impression). La page les liste.
- Outil autonome : mise en page d'un texte (titre, sous-titre, « # » parties, « - » puces) pour l'imprimer, l'enregistrer en PDF ou le télécharger en image.

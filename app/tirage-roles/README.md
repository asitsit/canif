# C15 : Tirage de rôles

Attribution de rôles au hasard. Adresse : `/tirage-roles`.

- Liste de noms (partagée avec les autres outils de tirage) et liste de rôles (gardée dans le navigateur).
- Cadres connus pour remplir la liste (`cadres.ts`) : rôles de réunion, six chapeaux de Bono, stratégie Disney, rôles d'équipe de Belbin, travail en sous-groupe. Un clic sur un rôle l'ajoute ou le retire.
- Plus de personnes que de rôles : les autres sont « sans rôle particulier ».
- Plus de rôles que de personnes : alerte visible avant le tirage, avec une option pour attribuer tous les rôles (certaines personnes en ont alors plusieurs). Sinon, les rôles en trop sont listés comme non attribués.
- Copier le résultat, plein écran. Raccourcis : Espace, F. Aucune donnée envoyée au serveur.

# C15 : Tirage de rôles

Attribution de rôles au hasard. Adresse : `/tirage-roles`.

- Liste de noms (partagée avec les autres outils de tirage) et liste de rôles (gardée dans le navigateur).
- Exemple de rôles : animation, gardien du temps, prise de notes, avocat du diable, observation.
- Plus de personnes que de rôles : les autres sont « sans rôle particulier ». Plus de rôles que de personnes : les rôles en trop sont signalés.
- Copier le résultat, plein écran. Raccourcis : Espace, F. Aucune donnée envoyée au serveur.

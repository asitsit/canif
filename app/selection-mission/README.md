# E5 : Matrice de sélection de mission

Adresse : `/selection-mission`.

- Sept critères préréglés (intérêt, rémunération, expertise, relation client, délai, potentiel, charge), modifiables.
- Verdict : 70 % et plus « Go », 50 à 70 % « À discuter », moins de 50 % « Non » (seuils choisis pour Canif).
- Comparaison de plusieurs missions. Même composant que la matrice de décision.

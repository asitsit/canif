# C33 : Palette de couleurs

Adresse : `/palette`.

- Harmonies à partir d'une couleur : camaïeu, couleurs voisines, complémentaire, triade.
- Couleurs dominantes d'une image (quantification simple, image traitée dans le navigateur).
- Codes HEX et RVB, contraste avec un texte blanc ou noir (niveaux WCAG AA, AAA). Copie des codes ou des variables CSS. Calculs dans `lib/couleurs.ts`.

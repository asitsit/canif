# F8 : Calcul du point mort

Adresse : `/point-mort`.

- Seuil = charges fixes / (prix - coût variable) ventes, et chiffre d'affaires correspondant.
- Date d'atteinte si le chiffre d'affaires prévu est régulier sur l'année ; marge de sécurité.
- Cas impossible (coût variable supérieur au prix) signalé.

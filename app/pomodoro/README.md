# C5 : Pomodoro

Minuteur de cycles travail / pause. Adresse : `/pomodoro`.

- Réglages : travail (25 min), pause courte (5 min), pause longue (15 min) tous les 4 cycles.
- Les étapes s'enchaînent automatiquement (désactivable), avec un signal sonore différent pour la fin du travail et la fin d'une pause.
- « Passer » va à l'étape suivante sans compter le cycle. « Tout recommencer » remet le compteur à zéro.
- Plein écran. Raccourcis : Espace, S, F.
- Aucune donnée envoyée au serveur.

# C11 : Ordre de passage

Tirage au sort de l'ordre de passage. Adresse : `/ordre-de-passage`.

- Affichage de l'ordre complet, ou révélation nom par nom (option).
- Copier le résultat, plein écran. Raccourcis : Espace (tirer ou révéler le suivant), F.
- Liste de noms partagée avec les autres outils de tirage. Aucune donnée envoyée au serveur.

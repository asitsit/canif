# G6 : Traitement de listes

Adresse : `/listes`.

- Traitements cumulables, appliqués dans l'ordre : espaces, lignes vides, majuscules, doublons, ordre, numérotation.
- Doublons : sans tenir compte des majuscules et accents par défaut (option stricte).
- Tri français avec nombres naturels (2 avant 10), tri par longueur, inversion, mélange.
- « Remplacer ma liste par le résultat » pour enchaîner. Aucune donnée envoyée au serveur.

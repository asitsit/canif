# C29 : Tableau blanc simple

Adresse : `/tableau-blanc`.

- Outils : sélection, rectangle, ellipse, flèche, texte, crayon ; six couleurs, épaisseur réglable.
- Sélection : déplacer, supprimer (Suppr), double-clic pour modifier un texte. Annuler (50 étapes).
- Dessin en SVG (1600 × 900), export PNG, PDF ou SVG. Tableau gardé dans le navigateur.
- Version simple : pas de redimensionnement des formes ni de travail à plusieurs.

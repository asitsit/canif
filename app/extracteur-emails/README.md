# G5 : Extracteur d'adresses e-mail

Adresse : `/extracteur-emails`.

- Retrouve les adresses dans n'importe quel texte, sans doublons (majuscules ignorées).
- Séparateur au choix (ligne, virgule, point-virgule pour Outlook), tri, filtre par domaine (sous-domaines compris).
- Motif volontairement simple : couvre les adresses courantes, pas tous les cas permis par la norme.
- Analyse dans le navigateur. Rappel RGPD affiché.

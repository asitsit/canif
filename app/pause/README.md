# C4 : Écran de pause

Écran à projeter pendant une pause. Adresse : `/pause`.

- Durée en un clic (5 à 60 min) ou heure de reprise précise.
- Message personnalisable (« Pause café », « Déjeuner »...).
- Affiche l'heure actuelle, l'heure de reprise et le temps restant ; « C'est l'heure de reprendre ! » à la fin, avec un signal sonore optionnel.
- +5 min, terminer la pause, plein écran (touche F).
- Aucune donnée envoyée au serveur.

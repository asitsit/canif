# F2 : Rentabilité de mission

Adresse : `/rentabilite-mission`.

- Gain par jour réellement passé = (CA - frais - sous-traitance) / jours réels.
- Comparaison avec un objectif journalier : rentable, limite (moins de 20 % sous l'objectif), peu rentable.
- Coût du dépassement de temps en journées vendables. Réglages gardés dans le navigateur.

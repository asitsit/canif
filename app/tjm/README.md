# F1 : Calculateur de TJM

Adresse : `/tjm`.

- Modèle transparent : CA nécessaire = (revenu net visé + frais) / (1 - taux de prélèvements) ; TJM = CA / jours facturés.
- Jours facturés = 261 jours ouvrés - congés - fériés - jours non facturables, × taux d'occupation.
- Le taux de prélèvements est saisi par la personne : aucune valeur n'est présentée comme officielle (il dépend du statut et de l'année). Note visible dans l'outil.
- Tableau de sensibilité selon le taux d'occupation (50 à 100 %). Réglages gardés dans le navigateur.
